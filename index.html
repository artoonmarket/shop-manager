🛍️ Խանութի Կառավարիչ

Մեկ անգամ տեղադրեք Apps Script URL-ը — հետո ամեն ինչ ավտոմատ կաշխատի:

Քայլ 1. Բացեք ձեր Google Sheet → Extensions → Apps Script
Քայլ 2. Ջնջեք ամեն ինչ → Paste արեք Code.gs-ի ամբողջ կոդը → 💾 Save
Քայլ 3. Սեղմեք Deploy → New deployment
Քայլ 4. Type: Web app · Execute as: Me · Who has access: Anyone
Քայլ 5. Սեղմեք Deploy → copy-paste արեք URL-ը ներքևի դաշտ
